# 検証記録

## 実施範囲

Windows 11（build 26300）、Windows on ARM上でMSVCによるx64／ARM64ビルドと安全な自己テストを実行します。自己テストは実desktop切替・実キー入力・startup変更を行いません。MCPはSDKクライアントによる初期化・ツール一覧・読み取り専用statusの往復を確認します。

資源測定は利用者の追加許可後、専用のper-user配置先の実行ファイルと、実際にDefaultで起動した常駐のPID／実行パス／ハッシュを照合して行います。自動起動・タスクスケジューラ・サービス・MCP設定は登録しません。測定結果は取得後に追記します。

## 未検証

別プログラムが作成した実desktopへの切替、物理Home/Esc復旧、切替直前／直後のキー配送競合、UAC／ロック中の実動作、複数ツール併用、異なるWindowsビルド、長時間運用は未検証です。復旧応答時間の実機値は未計測です。モックによる復旧成功・失敗・競合判定のテストは、実機での復旧可能性の保証ではありません。
